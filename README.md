A program that writes exactly one pickup line to `/output/entry.txt`, for the
[make.fun competition](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1).

## The line

> **Watchdog Timer.** *"You must be my watchdog timer — every time I start to drift, you reset me back to you."*

A watchdog timer resets a drifting machine back to safety. Here every reset
lands back on the beloved — machine-to-machine, warm, and an angle no other
entry in the field used.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is a plain static writer: no network, no secrets, no dynamic
code, no reads outside the repository.
